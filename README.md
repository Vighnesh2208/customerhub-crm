# CustomerHub CRM

A modern customer relationship management dashboard with WooCommerce REST API integration.

## Project Structure
- `backend/`: Node.js + Express API server with WooCommerce REST API v3 integration and demo mode.
- `frontend/`: React + Vite frontend interface.

## Quick Start (Backend)
```bash
cd backend
npm install
npm test
npm start
```

For full backend details, see [backend/README.md](backend/README.md).
